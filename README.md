# To-Do List React App

A simple, beautiful, and responsive To-Do List application built with **React** and **Tailwind CSS**, featuring:

- Dark mode toggle 🌙 / ☀️
- Add, edit, delete, and complete tasks
- Set deadlines and priorities (High, Medium, Low)
- Filter tasks by status (All, Completed, Incomplete)
- Sort tasks by deadline, priority, or status
- Overdue task reminders with animation
- Responsive design and accessible UI

## Features

- Manage your tasks easily and efficiently
- Intuitive user interface with keyboard accessibility
- Persistent data storage using localStorage
- Real-time dark mode switching with smooth transitions
- Validation for deadlines to avoid past dates
- Color-coded priorities for quick identification
- Responsive layout optimized for desktop and mobile
